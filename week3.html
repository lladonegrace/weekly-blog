March 9 – March 13, 2026

System Development Phase and Menu Frontend Implementation

During this week, we started the development phase of the POS system. I was responsible for coding and implementing different functionalities while collaborating with the development team. My tasks mainly focused on frontend development, particularly converting the approved UI designs into functional system pages.

I worked on developing the frontend of the menu page, ensuring that menu items, layouts, and navigation were properly displayed and easy to use. I also refined interface components and maintained consistency between the design prototype and the actual implementation of the system.

Through continuous coding and development activities, I gained more experience in frontend implementation, interface integration, and collaborative system development. This week improved my understanding of how prototypes are transformed into fully functional system components.
